# Hopfion eigenmodes

Interactive supplementary visualizations for the n = 63, Ku = 0.002 Torus batch.

[Open the results viewer](https://lzy11231212-creator.github.io/hopfion-results/)

The gallery contains 17 configurations and 10 modes per configuration. Each mode
has 30 phases and supports rotation, roll, pan, zoom, phase selection, and playback.
The displayed mz = 0 surface is colored by atan2(my, mx).

Animations use the existing display amplification of 100 and a 3-second phase
cycle at the default playback speed. Playback speed is for viewing, not physical
simulation time. Cubic interpolation is a display step applied to the 1 nm source
grid; the original eigenmode fields are unchanged.

Losslessly compressed display-surface assets are served by the numbered
hopfion-n63-ku002-data repositories in this account. Each resource site remains
below the GitHub Pages size limit. The viewer loads only the selected mode.
